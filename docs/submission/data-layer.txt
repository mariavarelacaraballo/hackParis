NEUROVOICE — THE DATA LAYER IN ACTION

WHAT DATA THE AGENT USES
1. Personal memory of the user (Lucas): every sentence he said or chose, with who he was talking to, when, the previous utterance and his state. Plus contacts, routines and profile.
2. Live session: who is present and the last thing they said (speech-to-text via OpenAI; audio is never stored).
3. Wearable stream: heart rate, electrodermal activity and movement every 10 s (WESAD wrist data, recorded and replayed in real time) -> arousal estimate -> suggested voice tone.
4. Every choice and correction the user makes (this is how the agent learns).
5. Every agent step, latency and cost (traceability and evaluation).

WHERE IT LIVES (all on Aiven, EU)
- Aiven PostgreSQL + pgvector: users, contacts, routines, memories (with OpenAI embeddings, vector(1536)), choices, agent_log.
- Aiven Valkey: session (session:{user}), wearable state (state:{user}), caches for expansions and audio.
- Aiven ClickHouse: wearable_samples time series, per-request metrics (latency, cost), benchmark_results.
- Aiven Runtime: the FastAPI app with the agent (Dockerfile in repo), public URL.

HOW IT FLOWS (one request)
1. Wearable window -> POST /wearable/samples -> state model (logistic regression, trained on WESAD, LOSO 95 %) -> ClickHouse (series) + Valkey (current state).
2. Partner speaks -> POST /listen -> text -> Valkey session.
3. User types initials "m d l e" -> POST /expand -> agent:
   a. search_memory: PostgreSQL, exact initials + same interlocutor + usage frequency (pgvector similarity when there are no initials)
   b. get_context: Valkey session (who, last utterance, time)
   c. get_state: Valkey wearable state
   d. Claude (tool use; web_search via Keenable when the sentence is about current events) -> 5 candidate sentences + suggested tone + one-line reason
   Every step -> PostgreSQL agent_log; latency and cost -> ClickHouse metrics.
4. User selects (eye-gaze dwell) -> POST /choice -> PostgreSQL memory updated (times_used +1, or new memory if edited) -> the next prediction already uses it.
5. POST /speak -> ElevenLabs eleven_v3 with the tone tag -> audio (cached in Valkey).

REAL AGENT TRACE (from /expand, live run)

1 search_memory {"initials":"m d l e","interlocutor":"Rosa"} -> "Me duele la espalda, cámbiame de postura" (used 5 times), ...

4 propose -> ["Me duele la espalda, cámbiame de postura", ...]
